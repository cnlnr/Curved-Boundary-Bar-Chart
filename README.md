# Curved-Boundary Bar Chart (曲界线柱状图)

> 带有弯曲判定边界的动态柱状图组件，形态与原理类似物理学中的“三相图”。

## 💡 简介

**Curved-Boundary Bar Chart（曲界线柱状图）** 是一种新型的交互式数据可视化组件，其呈现形态与物理学中的“三相图”非常类似。

它通过控制柱体在 X 轴上的**平移位置**与 Y 轴上的**柱体高度**，利用柱体顶点与坐标系中弯曲临界线（Curved Boundaries）的碰撞，动态判定并展示当前的物理状态或业务区间。

## ✨ 核心特性

- **曲界碰撞判定**：以弯曲曲线为动态边界，柱体顶点穿过即可实时触发状态变更。
- **二维参数映射**：X 轴（如压强 P）映射柱体位置，Y 轴（如温度 T）映射柱体高度。
- **状态全覆盖**：支持固态、液态、气态及超临界流体等多相态的边界判定。
- **HiDPI 高清渲染**：基于 Canvas 物理像素缩放，自动适配 Retina 高分屏。
